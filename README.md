Velora Recipe Book

A highly interactive Recipe Book made using only:
- HTML5
- CSS3
- Vanilla JavaScript

## Dynamic features
- Search
- Category filtering
- Sorting
- Grid/list view
- Favorites
- Recipe detail modal
- Star ratings
- Add custom recipes
- Delete custom recipes
- LocalStorage persistence
- Dark/light theme
- Animated background particles
- Responsive mobile layout
- Live recipe statistics
- Toast notifications

## Run
Open `index.html` in a browser, or use VS Code Live Server.

No Node.js, React, database or backend is required.

## Image correction
The recipe cards use food-specific image URLs instead of generic/mismatched food photos. The image mapping was corrected for Indian dishes, desserts, pasta, pizza, salads, curry and breakfast items.
